# 项目交接说明

本项目已不再使用“跨多轮聊天 HANDOFF 文档”作为长期项目知识主入口。

当前开发模式：

```text
一个 PR = 一个独立 Agent 对话
```

开始新 PR 前请优先阅读：

1. `/AGENTS.md`
2. `/docs/PROJECT_RULES.md`
3. `/README.md`
4. `/docs/api.md`

跨 PR 长期规则的唯一主入口是 `/docs/PROJECT_RULES.md`。本文件不再是规则来源。

旧历史交接材料已移动到：

```text
docs/archive/HANDOFF_legacy.md
```

历史文件只用于追溯，不代表当前项目规则。
