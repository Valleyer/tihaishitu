# 游戏图片资产生成与替换总表

本文件是项目所有图片的统一登记表，记录图片用途、当前尺寸、建议生成尺寸、提示词、文件名与替换位置。当前地图图片只是开发期占位图，分辨率约为 `831×465`，在大屏幕上可能发糊。重新生成后，保持**文件名和路径不变**直接覆盖即可，代码与配置不需要修改。

以后新增任何图片，都要先在本文件追加一项，至少写清：用途、当前尺寸、建议尺寸、提示词、项目路径、浏览器路径、关联配置。替换图片时也要同步更新“当前尺寸”和必要的取景说明，避免出现有文件却不知道如何重做的情况。

## 一、统一规格

- 建议生成尺寸：`1920×1080`，横向 `16:9`。
- 最低可用尺寸：`1600×900`。
- 文件格式：优先使用高质量 JPG；质量建议 88–92，单张尽量控制在 1 MB 内。
- 构图用途：游戏主场景会铺满中间区域，上方和左下方会叠加地点名、环境说明与人物入口。
- 统一画风：原创古风游戏场景插画，细腻线稿结合水墨设色，建筑结构可信，色彩以深青、黛绿、木色和暖金为主。
- 统一限制：不要文字、题字、招牌字、界面、边框、Logo、水印；不要把重要主体紧贴边缘；不要使用摄影照片质感。
- 覆盖目录：`frontend/public/art/locations/`。

## 六、替换后的检查

替换完成后，在 `frontend` 目录运行：

~~~powershell
npm run dev
~~~

进入游戏依次前往七个地点，重点检查：地点标题是否清楚、人物入口是否遮挡主体、背景是否被过度裁掉。若主体位置需要调整，只改 `frontend/src/content/maps.json` 中相应地点的 `position`，例如 `"position": "60% 45%"`，不必重新生成图片。
