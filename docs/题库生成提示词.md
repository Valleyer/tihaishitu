# 《题海仕途》全服题目批次生成提示词

> 维护约定：本文件是正式导入格式 `global-question-batch/v2` 的唯一生成规范。代码调整字段或校验规则时，必须在同一次修改中同步更新本文和 `frontend/public/examples/题库示例.json`，并运行后端导入集成测试。

将本文件连同原始试卷 PDF、题目、教材或讲义交给其他 AI。AI 必须依据原始资料生成一份可直接导入《题海仕途》管理后台的 UTF-8 JSON 文件。

## 生成任务

从输入资料中提取原题，生成全服 Question Batch。输出只负责：

1. Question；
2. Question Option；
3. Question 与全局 KnowledgePoint 的关系。

导入文件生成的是全服 Question，不是 Book。Book 不参与题目导入，也不允许出现在 JSON 中。一年真题是一份 Question Batch，不是一本书。Question 绑定全局 KnowledgePoint 后，包含这些 KnowledgePoint 的 Book 会自动获得相应的潜在训练资源。

只录入原题，不自动补充变式题，不把年份或整套试卷创建为 Book。2026、2025、2024 等年份应分别生成独立 Question Batch，并汇入同一个全局 `question_resource` 资源池。

## 输出要求

- 只输出一个合法 JSON 对象，不要输出 Markdown 代码围栏、解释或注释。
- 顶层 `schemaVersion` 必须严格为 `global-question-batch/v2`。
- 默认 `publish=false`，使新题进入 `pending_review`。
- 顶层不得包含 `bank`、`book`、`targetBookId`、`weight`、`enabled`、`chapter`。
- 所有 Question 使用标准 UUID。修订已有题目时必须继续使用原 UUID。
- Markdown 与 LaTeX 保留在 `content`、`analysis`、`standardAnswer` 或选项文本中；不要生成 HTML。
- JSON 中 LaTeX 的反斜杠必须正确转义，例如 `\\frac{1}{x}`。

## 顶层结构

```json
{
  "schemaVersion": "global-question-batch/v2",
  "publish": false,
  "batch": {
    "subject": "数学一",
    "sourceType": "real_exam",
    "sourceName": "全国硕士研究生招生考试数学一",
    "examYear": 2025
  },
  "questions": []
}
```

### batch

- `subject`：必填，必须与所有引用 KnowledgePoint 的 `subject_name` 一致。
- `sourceType`：只能是 `real_exam`、`mock`、`custom`。
- `sourceName`：必填，同一文件共享同一来源名称。
- `examYear`：`real_exam` 必填整数，其他来源可省略。

同一文件中的题目不得重复保存 batch 字段。

## Question 结构

```json
{
  "id": "11111111-1111-4111-8111-111111111111",
  "questionNumber": "1",
  "questionType": "single_choice",
  "presentationType": "single_choice",
  "gradingMode": "auto",
  "content": "设 $f(x)$ 满足……",
  "standardAnswer": "A",
  "analysis": "由极限定义可知……",
  "difficulty": 3,
  "options": [
    { "key": "A", "text": "$0$", "correct": true, "sortOrder": 0 },
    { "key": "B", "text": "$1$", "correct": false, "sortOrder": 1 }
  ],
  "knowledgePoints": [
    { "code": "M1-H01-001", "role": "core", "sortOrder": 0 }
  ]
}
```

- `id`：标准 UUID，批次内唯一。
- `questionNumber`：`real_exam` 必填，且同一批次内唯一；其他来源可选。原题有小问时保留在同一个 Question 中。
- `content`、`standardAnswer`、`analysis`：必填。题干与解析使用 Markdown + LaTeX。
- `difficulty`：整数 1～5。
- `options`：始终提供数组；自评题使用空数组。
- `knowledgePoints`：始终提供数组，数量 1～3，code 不得重复，至少一个 `core`。

## 原始题型必须保留

不得把填空题或解答题改造成选择题。字段组合只能使用：

| 原题型 | questionType | presentationType | gradingMode |
| --- | --- | --- | --- |
| 单选 | `single_choice` | `single_choice` | `auto` |
| 多选 | `multiple_choice` | `multiple_choice` | `auto` |
| 判断 | `true_false` | `true_false` | `auto` |
| 填空 | `blank` | `self_assessment` | `self_assessment` |
| 解答 | `solution` | `self_assessment` | `self_assessment` |

填空与解答题的 `standardAnswer` 必须是完整 Markdown 字符串，供用户作答后对照自评。

## 客观题选项和答案

- 客观题必须有 2～6 个选项，`key` 唯一。
- 单选题恰好一个 `correct=true`。
- 多选题至少两个 `correct=true`。
- 判断题恰好两个选项和一个正确项，建议 key 使用 `true`、`false`。
- `standardAnswer` 必须与 correct 标记完全一致：
  - 单选：字符串，例如 `"A"`；
  - 多选：字符串数组，例如 `["A", "C"]`；
  - 判断：布尔值 `true` 或 `false`。
- 自评题不得包含选项。

## KnowledgePoint 标注

每题只能绑定 1～3 个足够细的全局知识点：

- code 必须来自提供给你的正式 KnowledgePoint 清单；禁止自造 code。
- KnowledgePoint 必须处于 active 状态且科目与 `batch.subject` 相同。
- `core` 表示这道题主要训练、主要考查的知识点；至少一个。
- `auxiliary` 表示解题需要但并非主要训练目标的知识点。
- 同一题不得重复绑定同一 code。
- 如果一道题需要大量标签，应重新分析并只保留真正决定解法的 1～3 个细分知识点。

## 真题身份和 UUID

系统把以下组合作为第一版真题自然身份：

```text
subject + sourceType(real_exam) + examYear + questionNumber
```

同一真题身份若数据库中已存在，必须复用原 Question UUID。使用不同 UUID 会被拒绝，以防同一道真题重复入库。

## 输出前自检

1. 顶层格式是否严格为 `global-question-batch/v2`。
2. 是否完全没有 Book、bank、chapter 或文集字段。
3. batch 科目、来源、年份是否统一且准确。
4. 真题 questionNumber 是否填写且批次内唯一。
5. 是否只录入原题，没有生成变式题。
6. 是否保留原始题型，填空和解答是否使用自评。
7. 客观题答案与 correct 标记是否完全一致。
8. 每题是否绑定 1～3 个 active、同科目的正式 KnowledgePoint，且至少一个 core。
9. difficulty 是否为 1～5。
10. UUID 是否稳定；已有题目是否复用原 UUID。

满足全部条件后，只输出最终 JSON。
