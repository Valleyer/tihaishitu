# 后端开发记录

## 2026-10-02：Java 17 后端与第一轮接口对接

### 技术基线

- Java 17、Spring Boot 3.5.16、Maven Wrapper 3.9.9。
- 本地服务端口 `12345`，生产接口前缀 `/api/v1`。
- 经典注解式 MVC 分层：Controller、Service、Store；数据访问使用 Spring JDBC。
- MySQL 5.7 为正式本地数据库，H2 MySQL 模式用于自动化测试。
- 密码等连接信息只由环境变量提供，仓库不保存本地凭据。

### 数据与标识

- 存档、文集、题目、知识点、课卷、作答记录的数据库主键均为 UUID。
- 内置旧题库的短 id 在首次入库时确定性转换为 UUID，重复初始化不会改变关联关系。
- `study_attempt` 保存发题时的题目与答案快照；题库后来修订也不会改变已经发出的课卷。
- `answer_record` 通过游戏、课卷和题目 UUID 保存作答结果，同一课卷只能结算一次。

### 低流量策略

- `/bootstrap` 只返回存档摘要、文集 UUID、修订号和数量，不返回题目正文。
- 浏览器按文集 revision 下载 `/question-banks/{uuid}`，把 Markdown、选项和解析缓存到 IndexedDB。
- revision 未变化时直接使用浏览器缓存；短时离线可继续使用旧缓存。
- 答题请求只传 `attemptId`、`questionId` 和答案。
- 游戏历史在服务端响应中只传 `questionId`，HTTP 适配器从本地文集缓存补回题面。
- JSON 响应超过 1KB 时启用 HTTP 压缩。

### 已接通接口

- 启动数据、文集清单与按 UUID 下载文集。
- 新建、读取、删除、导出、导入存档。
- 地图移动、人物话题、县试报名。
- 开始、答题、下一题、结算和中止活动。
- 普通活动按 5 个不同知识点组织；主线与科举按 10 个不同知识点组织。
- 首题答错后留在同一知识点抽取低难度训练题，答对才进入下一个知识点；训练题不补分。
- 物品购买/使用、札记批注、配置调整、章节确认和故人里程碑。
